# Treasure 按钮配色进阶实施计划

## 目标

对系统设置页和插件管理页的按钮进行配色升级，引入四级按钮体系（墨紫、秋香、丹砂、素缟），通过微渐变与弥散阴影提升整体时尚感与专业度。

## 设计调性

Fashion、光线柔和（135deg 微渐变模拟自然光）、专业（语义清晰）、有文化内涵（传统色彩意象）。

## 四级按钮体系

| 等级 | 名称 | 功能 | 渐变 |
|------|------|------|------|
| Primary | 墨紫 / 丁香 | 查询、导入、保存、更新 | `#b095e2 → #8b6cc1` |
| Warning | 秋香 / 琥珀 | 还原、注册调试、同步 Manifest | `#eecb8e → #d6a758` |
| Danger | 丹砂 / 胭脂 | 删除操作 | `#df7d7d → #c95e5e` |
| Default | 素缟 / 月白 | 取消、编辑、视图未选中 | 半透明白底 + 暖棕边框 |
